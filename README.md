# Olimpia Launcher

Distribuição do launcher personalizado. Este repositório contém instruções e pacotes nas Releases.

## Primeira instalação

1. Feche o launcher.
2. Baixe o ZIP em [Releases](https://github.com/luquez/olimpia-launcher-releases/releases/latest).
3. Extraia o conteúdo para `_launcher/app` na instalação existente do cliente, substituindo os arquivos do launcher.
4. Abra pelo atalho Meu Launcher Olimpia.

O pacote não inclui o jogo completo. Preserve as demais pastas, preferências e configurações do bot.

## Atualizações seguintes

O launcher verifica novas versões ao abrir. Os pacotes são assinados e verificados antes da instalação. Se a instalação falhar, restaura a versão anterior. A atualização do jogo é separada.

Se o GitHub estiver indisponível, a versão instalada continua utilizável.
